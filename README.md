# 📁 桌面整理器

一键整理桌面文件，按类型自动分类！再也不用面对乱七八糟的桌面了。

##  功能特点

-  图形化界面，勾选即用
-  按文件类型自动分类（Word、Excel、图片、视频等）
-  单文件exe，无需安装Python
-  免费开源

## 📥 下载使用

1. 点击右侧 **Releases** → 下载 `桌面整理器.exe`
2. 双击运行（建议先放测试文件夹试一下）
3. 选择要整理的文件夹
4. 勾选要整理的文件类型
5. 点击"开始整理"

## 📁 分类规则

| 分类 | 包含格式 |
|------|----------|
| Word文档 | .docx, .doc |
| Excel表格 | .xlsx, .xls, .csv |
| 图片 | .jpg, .png, .gif, .bmp |
| 视频 | .mp4, .mkv, .avi |
| ... | ... |

## ❓ 常见问题

**Q: 提示"找不到xxx模块"？**  
A: 请下载Releases里的exe文件，不需要自己运行Python代码。

**Q: 杀毒软件报毒？**  
A: 这是误报！PyInstaller打包的exe有时会被误判，请添加信任即可[citation:8]。

**Q: 能整理其他文件夹吗？**  
A: 可以！点击"浏览"选择任意文件夹。
